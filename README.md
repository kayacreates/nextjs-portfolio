# Yearim Kim — Portfolio

Next.js portfolio converted from the original Figma AI / Vite export and customized for a WordPress + frontend developer portfolio.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS v4
- Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project is ready to import into Vercel from GitHub.

## Before public launch

Replace the contact placeholders in `src/app/components/Portfolio.tsx` with your exact email, LinkedIn URL, and GitHub URL. The original Figma prototype's fake form submission was intentionally removed.

The current project visuals are designed placeholders rather than stock photos. Replace them with real project screenshots when you have portfolio-ready images. The three featured stories currently cover Rivera Roofing, custom Gutenberg systems from Jordan Crown work, and Compass Health enterprise navigation.

Review any employer/client naming against confidentiality requirements before publishing publicly.
